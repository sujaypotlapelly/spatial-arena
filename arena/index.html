Try it yourself: fly a drone through the factory scan

Each second a flight program receives the drone's instrument readings as text and sends back one command. Below, Ripple's flight program flies one route; drag the timeline to read what it received and sent at any second. Flights run on this device with the benchmark's simulator. No model runs on this page and nothing is sent anywhere.

This browser does not reproduce the benchmark's flights exactly, so scores here can differ from the published ones. Details below the flight.
